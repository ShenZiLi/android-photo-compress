# 修复已压缩网格默认标签误切换

## Goal

从已压缩图集进入图片网格时默认全部，排查并修复偶发已跳过误切换，验证并本地提交。

## Requirements

- 每次从已压缩图集进入图片网格，默认选中“全部”，包括返回后重进和进入其他图集。
- 修复进入页面时的误触路径，保留用户主动筛选、选择与还原，以及原有页面动效和无障碍标签语义。
- 不操作个人媒体，仅提交本次变更；工作区既有压缩性能和 HEIC 修改由原任务处理。

## Acceptance Criteria

- [x] 检查默认标签及全部筛选写入来源，说明可信触发机制和验证边界，见 research/filter-entry.md。
- [x] 调试构建、全量 Lint 和差异检查通过。
- [ ] 真机交互回归：设备处于安全锁屏，本轮未执行普通进入、快速重复点击、返回重进、主动切换；未将源码推断写成实测复现。
- [x] 保存规范与任务检查记录；本地提交和会话记录随收尾完成，不推送。

## Notes

- 范围明确的轻量缺陷修复；用户已要求检查并修复，按该授权实施。
- 初步定位：openAlbum/backToAlbums 已设 filter="all"；只有 setFilter 会选择 skipped。页面即时可点击，图集连续点击的后续触摸可落到新页筛选栏，需要在触摸入口防误触。
