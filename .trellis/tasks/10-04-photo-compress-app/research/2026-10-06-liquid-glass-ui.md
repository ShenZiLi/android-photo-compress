# 轻存全局液态玻璃 UI

## 授权与目标

用户指定 ui-ux-pro-max、better-ui，要求美化整个 APP。沿用已批准操作流程与文案，在实际安装工程 `android-photo-compress` / `com.photocompress.app` 实施，版本更新为 0.1.12 / versionCode 13。

设计决策见 `design-system/qingcun/MASTER.md`；共享规则见 `.trellis/spec/android/ui-style.md`。

## 已实施覆盖

- 全局深浅色背景：静态环境光晕、系统动态主题色控件、墨绿 / 银白承载层。
- 首页：复用玻璃材质升级主卡、两个统计卡与数量 / 占用对比，保持全部数字口径、列对齐、居中和负号规则。
- 导航与动作条：浮动玻璃胶囊，原四入口、状态语义、压缩 / 还原进度及按钮。
- 图集两级：玻璃图集卡、清晰缩略图、同心圆角、选中边框、48dp 图集选择目标；图片网格与标签统一轮廓。
- 设置、图集过滤、质量档位、回收站：共享材质与高光图标、胶囊档位与开关外观；关于版本读取构建版本号。
- 提示、确认弹窗和信息面板：共享玻璃场景，弹窗及信息正文可滚动，确认 / 取消及危险操作行为保持。
- 文件访问入口：玻璃主按钮，保留原权限引导。

## 技术实现与限制

固定 Haze 1.6.10，使用背景 source 与 surface effect 分层采样；仅装饰背景进入模糊层。Haze 原生背景模糊与渐变边缘模拟液态玻璃视觉，不声称实现 Apple 原生光学折射。图片、文字和处理逻辑不参与模糊。列表项使用无模糊的材质变体，降低滚动绘制成本。没有常驻动画、传感器采样或新网络权限。

节电模式广播和恢复前台时重新读取高对比文字设置；SDK < 32 / 节电 / 高对比模式关闭模糊并使用回退承载色。按压动画 150ms、缩放 0.96、曲线 `(0.2,0,0,1)`，系统动画时长设置由 Compose 处理。
