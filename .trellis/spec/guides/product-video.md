# 产品视频素材与验证

介绍视频与 Android 业务修改分开；视频工程留在独立输出目录并固定制作工具版本。

- 真实界面截图保留来源、应用版本、设备或模拟器信息。拼接不同阶段必须按演示剪辑表达，不能伪称实时测速。
- 优先使用 `docs/screenshots/` 的合成演示媒体；连接真机时可采集不含个人数据的设置页。真机个人相册、统计、原始层级及媒体留在忽略目录，不进入成片或本地提交。
- 采集界面不自动执行压缩、还原、删除备份或改变用户设置。需要这些操作时依用户授权范围处理。
- 压缩收益只展示真实来源数据并标注演示结果，不承诺固定比例、无损或全部设备兼容；备份还原必须带有效期边界。
- 用户要求 `brag-output/` 作为本地忽略产物目录：可编辑工程、素材、成片、封面和配文保留在本地，不纳入 Git 跟踪。制作规范、忽略规则及会话记录继续提交；制作缓存、节点依赖、临时检查截图不提交。
- 视频验证应包括制作框架完整检查、场景与结尾画面目视检查、最终文件时长/分辨率/音视频轨道检查。封面选稳定且完整的画面，并验证首帧替换不改变时长和音频。
- 字体若使用本机系统字体，应注明跨平台重新制作的字体依赖；不将专有字体文件当作工程素材分发。
