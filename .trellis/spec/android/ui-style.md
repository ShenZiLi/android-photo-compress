# 轻存 UI 材质规范

全局视觉以 [液态玻璃设计规范](../../../design-system/qingcun/MASTER.md) 为准。

- 背景、玻璃材质、正文颜色由 Theme / GlassScene / GlassSurface 集中管理。系统动态色保留为控件主题色，统计图的数据语义色保持固定。
- 真机实际包为 `com.photocompress.app`，仅修改本工程；不可把另一工程的资源修改当作已部署。
- 场景采样层只包含装饰背景，照片与文字保持独立清晰。列表不逐项执行背景模糊。
- 将容器改为透明时，必须显式设置 Surface / Scaffold 的 `contentColor`，否则深色背景上标题可能继承默认黑色。
- 禁用按钮的渐变两端均保留低透明度；不可对已降低透明度的颜色再次 `copy(alpha = 1f)`，否则底部变为不透明亮色，误导用户可点击。
- 四入口导航、图集两级、选择、压缩、还原和确认行为保留。全图集勾选目标至少 48dp，使用原生 toggleable 语义；筛选用 selectable 状态并支持横向滚动。
- 紧凑筛选胶囊将 48dp 点击范围与 32dp 视觉层分离：外层 selectable 不绘制 indication，内层共享 InteractionSource，在圆角裁切内绘制中心扩散反馈。不得让外层点击反馈覆盖胶囊外的空白。
- 弹窗与信息面板正文可滚动；列表底部空间由 Scaffold 安全区分配，避免被浮动栏遮挡。
- 带返回按钮的顶栏默认保留 12dp 标题间距。压缩比例、图集过滤、回收站属于设置二级页，页面按钮与系统返回均回到设置，底部保持设置选中；弹窗/信息面板优先处理自身关闭。
- 不恢复用户明确删除的提示、统计卡或说明，文字修改遵循已有确认。
- 同一批次的相同错误/跳过原因按首次出现顺序去重，再取最多三种不同原因；项目成功/失败/跳过数量仍按实际项目统计。弹出提示中的相同文本行也去重。不可跨操作永久过滤同一原因，用户再次操作时仍需反馈。
- 不添加常驻动画或传感器采样；节电模式与高对比文字模式回退更实的玻璃承载色。
- 动效统一使用 `components/Motion.kt`：按压 120ms、状态 150ms、页面 220ms、退出 120ms，采用快速响应的缓出曲线。系统动画关闭、节电、键盘输入时新动效即时回退；主题变色直接应用新色。
- 页面只动画当前视图，不保留可点击旧页；过滤菜单的反馈须始终裁切在视觉胶囊内。列表仅动画位置变化，不为滚动出现的每张照片播放入场。数字即时显示真实值，进度只能平滑真实任务进度；退出确认弹窗时禁用操作，确认回调仅执行一次。
- 不把构建成功当作所有设备视觉验收通过。截图、原始 UI 层级与个人媒体留在忽略目录；未验证的主题、大字体、屏幕尺寸和性能必须注明。
- 回收站清理全部备份的删除图标放顶栏右侧，保留永久清理确认；空回收站或正在处理时禁用，不在列表底部重复放清理按钮。
- 回收站使用有稳定编号 key 的 LazyColumn 按需展示备份，顶栏固定在滚动区域外；不得在 verticalScroll 内一次性 forEach 绘制全部备份，避免大量记录超出 Compose 尺寸约束。
- 回收站列表、清理确认与实际清理均按 backupRelPath 非空取项，不限定 DONE；旧状态残留备份同样可清理。删除须校验应用私有目录边界、现有媒体状态和文件结果，按已删除编号分批登记。异常恢复备份、原片缺失时可能唯一剩下的备份及无账本备份禁止清理，提供恢复/导出入口；到期 Worker 使用同一保护规则。
- 压缩批次操作栏跨页面保留取消入口；取消后立即显示“正在取消”并禁用重复点击，待当前项安全回退及缓存更新后结束。之前完成的项目不还原，后续项目不开始。
