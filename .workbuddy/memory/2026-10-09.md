### 本会话踩到的坑（复用）

- 本会话环境注入的 `HTTP(S)_PROXY=127.0.0.1:54965` 是坏的，`git ls-remote`/`fetch` 报
  `CONNECT tunnel failed, response 502`；`gh` 自身不受影响。绕过方式：
  `env -u HTTPS_PROXY -u HTTP_PROXY -u ALL_PROXY -u https_proxy -u http_proxy -u all_proxy git <cmd>`。
- 触发 release 流水线前必须核对三件事：远端无同名 tag、`versionName` 与 tag 一致、`origin`
  没有他人刚推的同类发布（本仓库有两个会话并行写 dev/master，容易撞车）。
- YAML 语法校验：本机托管 Python 无 PyYAML，改用系统 ruby `-ryaml` 即可。
