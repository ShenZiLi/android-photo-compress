### 本机构建关键参数（复用）

```
export ANDROID_HOME=/Users/shen/.local/share/mise/installs/android-sdk/21.0
export ANDROID_SDK_ROOT=$ANDROID_HOME
export GRADLE_USER_HOME=<repo>/.tmp-device/gradle-user-home   # 必须，见下
./gradlew :app:assembleDebug
```

**坑：`~/.gradle/init.gradle` 注入阿里云 maven 仓库，与 `settings.gradle.kts` 的
`FAIL_ON_PROJECT_REPOS` 冲突导致构建失败。** 解法是使用独立 `GRADLE_USER_HOME`
（`.tmp-device/gradle-user-home`，其 `caches`/`wrapper` 软链到 `~/.gradle`），
该目录下无 init.gradle，绕开冲突且复用依赖缓存。

**坑：仓库内 `gradlew` 无执行权限（git mode 100644）**，已修正为 100755。

release 构建需要 4 个环境变量 `SIGNING_STORE_FILE` / `SIGNING_STORE_PASSWORD` /
`SIGNING_KEY_ALIAS` / `SIGNING_KEY_PASSWORD`，本机无 keystore，故走 debug 包。
