# 轻存 · 液态玻璃视觉规范

## 设计与边界

用户授权整个 APP 采用液态玻璃美化。实际工程为 `android-photo-compress` / `com.photocompress.app`，使用 Jetpack Compose。沿用首页 Bento 网格、图集两级结构、四个底部入口及所有已确认文案，不改变压缩、还原、账本、权限和文件写入行为。

采用 ui-ux-pro-max 的 Liquid Glass 材质指导及 better-ui 的同心圆角、轻阴影、图片细轮廓与按压反馈原则。设计系统检索中的网页 Hero / Testimonials 结构不适用于本工具，未采用；平台保持 Android 原生交互，不复制 iOS 导航行为。

## 材质

- 深色：墨绿黑背景，低饱和玉绿与系统主题色光晕，文字银白。
- 浅色：银白背景，柔和玉绿与系统主题色光晕，文字深墨绿。
- 卡片：24dp 圆角、真实背景模糊、渐变高光轮廓、轻阴影，文字与照片独立于模糊层。
- 导航：距左右各 16dp 的浮动玻璃胶囊，4 个入口，当前项为带高光的主题色胶囊。
- 操作条：独立玻璃卡片；压缩 / 还原按钮统一高光、48dp 触摸高度、禁用状态、系统点击反馈。
- 图片网格：原图缩略图保持清晰；16dp 圆角、白色 10% 细轮廓，选中状态有勾选与主题色边框。
- 档位与类型筛选：胶囊分段，当前项带颜色与文字状态；筛选支持水平滚动以容纳大字体。
- 信息面板、提示与确认弹窗：复用玻璃背景与圆角，正文保持高对比，取消 / 确认行为不变。

## 实现边界

修改集中在 `ui/theme`、共享组件、`RootScreen` 与各页面的外观层；版本与 UI 依赖随安装包更新。使用固定版本 Haze 1.6.10 对场景背景采样并模糊；高光与材质叠层模拟液态玻璃边缘，不声称实现 Apple 原生光学折射。列表条目和图片不逐格执行模糊，避免滑动时重复生成模糊层。不添加持续背景动画、传感器监听或网络权限。Android 低版本/高对比文字模式/节电模式使用更实的材质回退。

## 保留用户确认的规则

- 名称为轻存；首页“已省”、负号百分比；两个统计卡居中；不恢复第三个压缩率卡。
- 首页图例百分比和大小继续列对齐并右对齐。
- “数量对比”“占用对比”沿用，不恢复“体积对比”。
- 未选择时不恢复删除的引导小字；压缩比例入口不恢复说明。
- 压缩 / 还原消息和 MPF 跳过原因保持现有简洁文案。

## 检查范围

编译、差异审阅及 UI 资源检查；按已获授权的安装流程更新真机。没有单独授权时不运行测试套件、不触发压缩 / 还原 / 删除备份。触摸目标、禁用状态、深浅色令牌与滚动安全区从实现审阅；真机视觉截图和未覆盖设备/大字体等验收范围如实记录。
